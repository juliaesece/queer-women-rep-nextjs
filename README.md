Hi! This is the repo for [Everything Sapphic](https://everythingsapphic.com/).

![Screenshot of the site Everything Sapphic](https://uo1c7gutiu.ufs.sh/f/U882N2vdjsCnzlv2nV4YGNQbLWiwB583XEeglRShvxa1jtIP)

The site is built with [Next.js](https://nextjs.org/). It uses a MongoDB. 

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
